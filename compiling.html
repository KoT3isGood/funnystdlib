Compiling fpc

How to compile:


git clone https://github.com/KoT3isGood/funnystdlib
cd fpc
make
I don't think it was hard, was it?
We rely on Makefile to bootstrap, configure and deploy it
Now you can add build/tools/fpc to your PATH environment variable

Cross-compilation

You can cross-compile via FPC_ARCH, FPC_OS and FPC_ABI variables.
Example for iSH Shell, as it comes with sysroot for i586-alpine-linux-musl:
make FPC_ARCH=i586 FPC_OS=alpine-linux FPC_ABI=musl
