fpc command line reference

You can find every single command it uses

  • fpc build — Builds your project

    How it works

    1. goes down current working directory until finds build.cpp
    2. compiles and runs it's dependencies recursively
    3. runs all the scripts
    4. returns all the modules

    Arguments

    • -fpcdebug — prints all commands used
    • -arch — sets target CPU.
    • -os — sets target OS.
    • -abi — sets target ABI.
  • fpc target query — Returns ABI it was compiled for.
  • fpc --version — Tells information about the version.
  • fpc -v — Same as fpc --version
